🚀 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Update Field Names
────────────────────────────────────────────────────────────────────────
Open: lib/admin/services/admin_service.dart

Search for "NOTE:" comments and update field names to match your models.

Example:
  // BEFORE
  final status = user['status'];
  
  // AFTER (if your model uses 'userStatus')
  final status = user['userStatus'];

Find ~20 field name references to customize (comments guide you).


STEP 2: Create Admin User in Firestore
────────────────────────────────────────────────────────────────────────
In your Firestore 'users' collection, add a document:

{
  "uid": "admin_user_id",
  "name": "Admin Name",
  "email": "admin@example.com",
  "role": "admin",              ← MUST BE 'admin'
  "status": "approved",
  "phone": "+1234567890",
  "createdAt": "2024-01-01T00:00:00Z"
}


STEP 3: Import in Main App
────────────────────────────────────────────────────────────────────────
In your main.dart:

import 'admin/admin_shell.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(const MyApp());
}

// Use AdminShell as your home:
home: const AdminShell(),


✨ DONE! Test login with your admin credentials.

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Q: Login fails with "Admin privileges required"
A: Check that user's 'role' field in Firestore is set to 'admin'

Q: No data appears in dashboard
A: Check field names in admin_service.dart match your models

Q: Screens don't load real-time data
A: Verify Firestore rules allow read access to collections

Q: Mobile layout looks wrong
A: Check window width - breakpoint is 900px

For more help: See lib/admin/README.md troubleshooting section
