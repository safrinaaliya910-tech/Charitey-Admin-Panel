SCREEN BREAKDOWN
════════════════════════════════════════════════════════════════════════

1. LOGIN SCREEN (admin_login_screen.dart)
   ├── Email input field
   ├── Password input field (with toggle visibility)
   ├── Firebase Auth integration
   ├── Admin role verification
   ├── Error handling
   └── Desktop & Mobile layouts

2. DASHBOARD (admin_dashboard_screen.dart)
   ├── 8 Stat Cards (NGOs, Donors, Posts, Donations, etc.)
   ├── Recent Donations Feed
   ├── Recent Users Feed
   ├── Real-time data with StreamBuilder
   └── Loading skeletons

3. USERS MANAGEMENT (users_management_screen.dart)
   ├── Data table with columns (Name, Email, Role, Status, Actions)
   ├── Search box
   ├── Role filter (All, NGOs, Donors)
   ├── Status filter (All, Approved, Pending, Rejected, Blocked)
   ├── Actions: View, Approve, Reject, Block/Unblock
   └── User details dialog

4. POSTS MANAGEMENT (posts_management_screen.dart)
   ├── Data table with columns (Title, Category, Status, Date, Actions)
   ├── Search by title
   ├── Status filter
   ├── Actions: View, Mark Fulfilled, Archive, Delete
   └── Post details dialog

5. DONATIONS MANAGEMENT (donations_management_screen.dart)
   ├── Data table with columns (ID, Donor, NGO, Amount, Status, Actions)
   ├── Status filter
   ├── Actions: View, Update Status, Cancel
   └── Donation details dialog

6. VOLUNTEERS MANAGEMENT (volunteers_management_screen.dart)
   ├── Data table with columns (Name, NGO, Status, Joined, Actions)
   ├── Search by name
   ├── Status filter
   ├── Actions: View, Mark Available/Unavailable, Block/Unblock
   └── Volunteer details dialog

7. MESSAGES MONITORING (messages_monitoring_screen.dart)
   ├── Message list (read-only Phase 1)
   ├── Search conversations
   ├── Display: Sender, Receiver, Message text, Timestamp
   └── Conversation view

8. NOTIFICATIONS (notifications_management_screen.dart)
   ├── Notification list with type icons
   ├── Filter: All, Unread, Read
   ├── Actions: Mark Read, Delete
   ├── Type-based colors (error, warning, success, info)
   └── Timestamp display

9. SETTINGS (admin_settings_screen.dart)
   ├── Admin Profile Section
   │   ├── Avatar with initial
   │   ├── Name and email
   │   └── Admin badge
   ├── App Information Section
   │   ├── App name
   │   ├── Version
   │   └── Last updated
   └── Session Section
       └── Logout button with confirmation

ADMIN SHELL ROUTING
════════════════════════════════════════════════════════════════════════

AdminShell
├─ Check Authentication
│  └─ If not authenticated → AdminLoginScreen
│  └─ If authenticated → Main Admin Panel
│
├─ AUTHENTICATED STATE
│  ├─ AdminSidebar (Navigation)
│  ├─ AdminTopbar (Header)
│  └─ Current Screen (based on route)
│     ├─ dashboard
│     ├─ users
│     ├─ posts
│     ├─ donations
│     ├─ volunteers
│     ├─ messages
│     ├─ notifications
│     └─ settings
